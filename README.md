# 映伴 YingBan · Windows 正式预览 1.0

映伴是一个双人屏幕共享和语音通话原型，不需要注册账号或云服务器。两台 Windows 电脑可以在同一局域网内连接，也可以先加入同一个 Tailscale 网络。

## 使用

1. 把完整的 `YingBan-Windows` 文件夹复制到两台 Windows 11 x64 电脑，各自打开 `YingBan.exe`。不能只复制 exe。
2. 一方点击“创建通话”，选择邀请地址并复制给对方；Tailscale 地址通常以 `100.` 开头。
3. 另一方粘贴邀请地址，点击“加入通话”。创建和加入默认不会访问麦克风，也不会初始化音频输出，因此没有麦克风时仍可以观看和共享。
4. 需要说话时，点击“开启麦克风”，选择输入设备。蓝牙耳机可能切换 Windows 的通话模式；如果鼠标或声音变卡，可以先关闭蓝牙麦克风，改用 USB 或有线麦克风。
5. 点击“共享屏幕”，选择画质和共享源，再决定是否共享声音。
6. 结束时点击“停止共享”或“结束通话”。关闭麦克风会释放输入设备，停止共享会恢复应用原音量。

## 音频范围

- 选择一个应用窗口：只采集这个窗口所属应用及其子进程的声音。其他应用声音不会发送，也不会参与自动降音量。
- 选择整个屏幕：采集其他所有应用声音，同时排除映伴自己的通话进程，避免把对方声音回传给对方。
- 如果 Windows 无法安全识别某个窗口所属应用，映伴会停止电脑声音共享，不会退回成整台电脑采集。
- 同一个浏览器的多个标签页、同一应用的多个窗口可能共用音频进程，因此应用级声音边界取决于应用自己的进程结构。
- 双方都能发送麦克风。任意一方说话时，由共享端降低所选应用的声音；观看端只跟随这个已经降低的共享音频，不会重复降低。
- 共享者可以调整人声优先强度，观看者可以调整自己的共享声音收听音量。通话人声不经过共享声音降音量节点。

## 画质

共享画面有三档：

- 4K：3840×2160，最高 30 帧/秒，25 Mbps 上限，适合局域网和文字、代码。
- 1440p：2560×1440，最高 30 帧/秒，12 Mbps 上限。
- 1080p：1920×1080，最高 30 帧/秒，6 Mbps 上限，适合带宽有限的 Wi-Fi 或 Tailscale。

界面底部会显示实际采集或接收的分辨率、帧率、码率和 RTT。实际清晰度还会受网络拥塞、显卡编码能力、共享源大小和观看端窗口影响；4K 屏幕不代表所有应用窗口本身都有 4K 内容。

## 鼠标延迟与设备行为

创建通话时不会再打开麦克风、AudioContext 或电脑声音采集。房间号加入使用局域网 UDP 发现；跨网请使用邀请地址。麦克风和音频上下文都在用户明确开启麦克风或开始共享电脑声音时按需启动；麦克风打开有 8 秒超时，避免设备驱动卡住界面。若蓝牙驱动切换通话模式造成系统级延迟，使用有线或 USB 麦克风是更稳定的选择。

## 系统要求与限制

- Windows 11 x64 优先；电脑声音的进程级采集使用 Windows 11 的 WASAPI Process Loopback。Windows 10 版本只能使用语音或无电脑声音的屏幕共享。
- 只支持两台电脑、可信局域网或 Tailscale 直连。没有公网 TURN 中继、多人会议、摄像头、录制或自动重连。
- 应用声音来自所选范围；共享前请关闭不希望被听到的应用。
- 自动降音量使用带通滤波、门限、起声确认和约 650ms 保持时间。键盘声、外放漏音可能误触发，轻声可能漏判，可调节灵敏度。
- 共享端会临时调整所选 Windows 音频会话的音量；正常停止或关闭后恢复。独占音频、ASIO、DRM 内容和不暴露独立会话的应用不保证支持。
- 创建房间时映伴会请求 Windows 防火墙允许 TCP 43127 和 UDP 43128。若 UAC 被取消，需要在 Windows 防火墙中允许映伴，或用管理员 PowerShell 执行：`netsh advfirewall firewall add rule name="YingBan Signaling TCP" dir=in action=allow enable=yes profile=private,domain protocol=TCP localport=43127` 和 `netsh advfirewall firewall add rule name="YingBan Room Discovery UDP" dir=in action=allow enable=yes profile=private,domain protocol=UDP localport=43128`。不要把端口直接暴露到公网。
- 媒体通过 WebRTC 加密传输，邀请地址中的随机密钥是加入凭证。程序不保存音视频，也不连接第三方分析服务。

## 开发与验证

需要 Node.js、Windows 自带 .NET Framework x64 C# 编译器，以及已下载的 Electron 运行时。

```powershell
npm ci
npm test
npm run test:desktop
node tests/native.cjs
node tests/scope.cjs
npm run dist
node tests/packaged.cjs
python scripts/archive.py
```

1.0 界面将创建 / 加入、观看共享和设置分开；工具栏保留麦克风、共享、全屏、设置和结束通话图标。自动测试包含：无麦克风创建、麦克风显式开启和释放、真实 Windows 4K 窗口像素、应用级和整屏音频范围、排除映伴通话进程、应用级降音量、共享端和观看端全屏、1080p 档位、资源清理。测试麦克风使用浏览器生成的合成信号，不采集真实麦克风；测试音频使用低音量合成音，不保存录音文件。
